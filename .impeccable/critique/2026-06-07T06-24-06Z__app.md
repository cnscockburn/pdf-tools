## Anti-Patterns Verdict

**AI slop verdict:** No. The warm stone + amber system has clear authorship. Two-mode contrast (light Home / dark Viewer) is designed, not accidental. No gradient text, glassmorphism, identical card grids (tool grid is borderline but compact format saves it), or side-stripe borders (one permitted nav exception). Not AI-generated looking.

**Detector:** `detect.mjs` not bundled in this environment. Scan unavailable.

**Browser overlay:** Not available (no browser automation).

## Overall Impression

Real identity, real keyboard fluency, real design decisions. The main problems are discoverability gaps in a tool that rewards expertise but barely surfaces that it exists.

## What's Working

1. Two-mode contrast is a genuine design decision, not a reflex.
2. Keyboard flexibility is exceptional — comprehensive coverage across all modes.
3. Close-guard tab system is invisible when not needed, precise when it is.

## Priority Issues

**[P1] "All shortcuts" capability chip misfired** — opened file picker instead of shortcuts. Fixed: now opens KeyboardCheatSheet directly.

**[P1] First-run hint contrast too low** — text-stone-400 on stone-900/80 was ~2.5:1. Fixed: bumped to text-stone-300 on solid stone-900, added "select text to get quick options" hint for better annotation discovery.

**[P2] Inactive tab contrast fails WCAG AA** — stone-500 on stone-900 was ~2.6:1. Fixed: changed to stone-400 (~4.2:1).

**[P2] Recognition gap for annotation features** — addressed via improved first-run hint: "Press A to annotate — or select text to get quick options."

**[P2] Tool grid structurally uniform** — reordered TOOLS array by usage frequency: Merge, Compress, Redact, Split, Organize, Images to PDF.

## Persona Red Flags

**Alex (Power User):** Ctrl+S on unmodified file fires download guard with "no modifications" — feels like broken shortcut. Secondary pane has no close-split button of its own.

**Jordan (First-Timer):** Backend status dot has no text explanation. "All shortcuts" chip now correctly opens shortcuts. First-run hint updated for better clarity.

**Morgan (Researcher — project-specific):** Export Review Report is a headline feature buried in File menu with no secondary surface pointing to it. Replies are session-only — no warning existed. Fixed: warning added in reply compose UI.

## Minor Observations

- Filename edit `<button>` has no `aria-label` — will be announced as raw filename with no interaction hint.
- Privacy footer "How it works" dotted underline is semantically unusual (typically for abbreviations).
- Rearrange: selection tick uses `✓` emoji character — Lucide `Check` icon would be more reliable across font renderers.
- Side-by-side split divider (1px stone-700) disappears on wide monitors; 2px or amber-tinted would be more visible.
- "Set name" author badge label was ambiguous; fixed to "Add your name".

## Questions to Consider
