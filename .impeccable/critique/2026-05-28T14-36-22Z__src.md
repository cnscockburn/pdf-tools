## Priority Issues

### [P1] Annotation mode toolbar demands too much recall
Icon-only toolbar with 8 annotation types, no labels, no tooltips. Exceeds 4-item working memory limit. Fix: add text labels or persistent tooltip on focus.

### [P2] Note/comment popup uses parallel yellow design system
bg-yellow-50 border-2 border-yellow-400 creates a distinct mini-system breaking the stone+amber vocabulary. Fix: restyle to stone-900 border border-stone-700 with amber accents.

### [P2] SettingsDialog amber-500 vs brand-500
amber-500 (#f59e0b) in SettingsDialog vs brand-500 (#d97706) everywhere else. Visible brightness/saturation gap. Fix: swap amber-500 -> brand-500 in SettingsDialog.tsx (3 lines).
